# Счётчик матов для OBS

Локальное приложение: слушает речь стримера, находит маты и показывает их
количество в оверлее OBS с анимацией «+1» и звуком.

Схема: микрофон → распознавание речи → поиск матов → счётчик → WebSocket → HTML-оверлей.

> Сейчас это скелет: вместо распознавания речи работает заглушка, которая
> раз в 5 секунд «произносит» тестовую фразу. Настоящее распознавание (Vosk)
> будет подключено позже.

## Установка

Нужен Python и виртуальное окружение `.venv` в корне проекта.

```powershell
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Запуск

```powershell
.venv\Scripts\python.exe -m app.main
```

Сервер работает только на этом компьютере (`127.0.0.1:8765`). Остановить: `Ctrl+C`.

- Оверлей для OBS: http://localhost:8765/overlay/
- Страница управления: http://localhost:8765/control/

Значение счётчика хранится в `counter.json` и не теряется после перезапуска.

## Добавление в OBS

1. В нужной сцене в «Источниках» нажмите **+** → **Браузер**.
2. **URL:** `http://localhost:8765/overlay/`
3. **Ширина / высота:** например `400` × `300`. Для крупного шрифта увеличьте оба размера, чтобы надпись «+1» не обрезалась сверху.
4. Включите **«Управлять звуком через OBS»**: тогда звук «дилинь» появится в микшере OBS и попадёт в эфир.
5. Пользовательский CSS можно не трогать: фон оверлея и так прозрачный.

Параметры оверлея задаются в адресе:

| Параметр   | Что делает                       | По умолчанию |
|------------|----------------------------------|--------------|
| `size`     | размер числа в пикселях          | `120`        |
| `color`    | цвет числа (hex без `#`)         | `ffffff`     |
| `mute=1`   | отключить звук                   | звук включён |

Пример: `http://localhost:8765/overlay/?size=160&color=ffcc00`

Если приложение запущено после OBS или было перезапущено, оверлей
переподключится сам в течение пары секунд.

### Свой звук

Положите файл `overlay/sounds/ding.mp3`, и он будет играть вместо встроенного
синтезированного звона.

## Страница управления

Откройте http://localhost:8765/control/ в обычном браузере (в OBS её добавлять
не нужно). Там видно текущее значение и состояние подключения, есть кнопки
«+1 (тест)» и «Сбросить».

Если открыть оверлей в обычном браузере, звук заиграет только после первого
клика по странице: так браузеры защищаются от автозапуска звука. В OBS это не требуется.

## Список слов

Корни для поиска лежат в `words.txt`, по одному на строку. Слово засчитывается,
если начинается с одного из корней. Регистр и ё/е не важны, пустые строки и
строки с `#` пропускаются. После правки файла перезапустите приложение.

## Структура

```
app/main.py        точка входа
app/server.py      FastAPI: /ws, /api/state, /api/increment, /api/reset, статика
app/counter.py     счётчик и сохранение в counter.json
app/profanity.py   поиск корней из words.txt
app/paths.py       пути к файлам (работают и из исходников, и из exe)
app/stt/           распознавание речи (сейчас заглушка FakeRecognizer)
overlay/           оверлей для OBS
control/           страница управления
```
