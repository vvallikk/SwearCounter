# Счётчик матов для OBS

Локальное приложение: слушает речь стримера, находит маты и показывает их
количество в оверлее OBS с анимацией «+1» и звуком.

Схема: микрофон → распознавание речи → поиск матов → счётчик → WebSocket → HTML-оверлей.

Речь распознаётся офлайн через [Vosk](https://alphacephei.com/vosk/):
интернет не нужен, звук никуда не отправляется.

## Установка

### Готовая программа (Windows)

1. Скачайте `SwearCounter-vX.Y.Z-windows.zip` со страницы
   [Releases](https://github.com/vvallikk/SwearCounter/releases) и распакуйте в любую папку.
2. Запустите `SwearCounter.exe`. Откроется окно консоли с адресами оверлея и
   страницы управления — не закрывайте его, пока идёт стрим.
3. Откройте страницу управления и нажмите на модель распознавания: она скачается
   и включится сама.

Настройки, счётчик, звуки и модели хранятся рядом с exe. Python не нужен.

### Из исходников

Нужен Python и виртуальное окружение `.venv` в корне проекта.

```powershell
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### Модель распознавания

Приложение работает с моделями из каталога `app/stt/catalog.py`. Скачивать их
вручную не нужно: нажмите на нескачанную модель на странице управления, и
приложение само скачает архив по ссылке из каталога, распакует его в папку
`models/` и включит модель.

| Модель    | Архив                                                                   | Скачать | На диске | Память  | Загрузка  |
|-----------|-------------------------------------------------------------------------|---------|----------|---------|-----------|
| Маленькая | [vosk-model-small-ru-0.22](https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip) | 45 МБ   | 90 МБ    | ~0,3 ГБ | ~1 с      |
| Большая   | [vosk-model-ru-0.42](https://alphacephei.com/vosk/models/vosk-model-ru-0.42.zip)             | 1,8 ГБ  | 3,5 ГБ   | ~5,5 ГБ | 1,5–2 мин |

Можно и вручную: распакуйте архив так, чтобы получилось
`models/vosk-model-small-ru-0.22/am, conf, graph, ...`

Маленькая быстрая, но распознаёт хуже; большая заметно точнее, но требует много
памяти. По умолчанию запускается первая скачанная модель из каталога; если не
скачано ни одной, приложение всё равно запускается и ждёт выбора на странице управления.
Выбор на странице управления сохраняется в `settings.json`.

Чтобы добавить модель, допишите её в `CATALOG` в `app/stt/catalog.py`:
название, описание, характеристики и ссылку на архив.

## Запуск

```powershell
.venv\Scripts\python.exe -m app.main
```

Ключи запуска:

| Ключ             | Что делает                                                 |
|------------------|------------------------------------------------------------|
| `--list-devices` | показать звуковые устройства и выйти                       |
| `--device N`     | слушать устройство с номером `N` или по части названия     |

Микрофон удобнее выбирать на странице управления (см. ниже). Ключ `--device`
нужен, только чтобы задать его при запуске; он важнее выбора на странице:

```powershell
.venv\Scripts\python.exe -m app.main --list-devices
.venv\Scripts\python.exe -m app.main --device 1
```

Сервер работает только на этом компьютере (`127.0.0.1:8765`). Остановить: `Ctrl+C`.

Если порт 8765 занят другой программой, приложение само попробует 8766, 8767
и так далее (до 8774) и напишет в консоли, какой адрес получился. В этом случае
адрес оверлея в OBS нужно поменять на новый или освободить порт 8765.

- Оверлей для OBS: http://localhost:8765/overlay/
- Страница управления: http://localhost:8765/control/

Значение счётчика хранится в `counter.json` и не теряется после перезапуска.

## Добавление в OBS

1. В нужной сцене в «Источниках» нажмите **+** → **Браузер**.
2. **URL:** `http://localhost:8765/overlay/`
3. **Ширина / высота:** например `400` × `250`. Число само растягивается под эти размеры,
   поэтому размер счётчика удобно менять здесь, а не растягивать источник мышкой
   (растягивание мышкой может исказить пропорции).
4. Включите **«Управлять звуком через OBS»**: тогда звук «дилинь» появится в микшере OBS и попадёт в эфир.
5. Пользовательский CSS можно не трогать: фон оверлея и так прозрачный.

Параметры оверлея задаются в адресе:

| Параметр   | Что делает                       | По умолчанию |
|------------|----------------------------------|--------------|
| `size`     | размер числа в пикселях          | под размер окна |
| `color`    | цвет числа (hex без `#`)         | `ffffff`     |
| `mute=1`   | отключить звук                   | звук включён |
| `preset`   | закрепить оформление (см. ниже)  | выбранное на странице управления |

Пример: `http://localhost:8765/overlay/?size=160&color=ffcc00`

Оформление (шрифт, цвет и анимация) выбирается на странице управления и меняется
в OBS сразу. Пресеты: `classic`, `impact`, `neon`, `retro`, `minimal`, `explosion`,
`ferret` (описаны в `overlay/presets.js`). Параметр `color` в адресе важнее цвета пресета.

Если приложение запущено после OBS или было перезапущено, оверлей
переподключится сам в течение пары секунд.

### Свой звук

Громкость и звук задаются на странице управления (см. ниже). Если выбран
«Стандартный звон», играет `overlay/sounds/ding.mp3`, а если нет и его — встроенный
синтезированный звон.

### Спешл «Хорёк 🐾»

Пресет `ferret` для хорьковых стримов: число исполняет «военный танец» хорька,
под ним пробегает хорёк и оставляет следы лапок, а вместо «+1» выскакивает «гу-гу!».
Стандартный звук у этого пресета — гуканье хорька,
`overlay/sounds/ferret.wav` (запись предоставлена автором проекта), а если файла
нет — синтезированное «гу-гу-гу-гу». Звук из библиотеки,
если он выбран, играет вместо стандартного, как и в других пресетах.

## Страница управления

Откройте http://localhost:8765/control/ в обычном браузере (в OBS её добавлять
не нужно). Там видно текущее значение и состояние подключения, есть кнопки
«+1 (тест)» и «Сбросить» (сброс подтверждается вторым нажатием). Под ними —
адрес оверлея для OBS: нажмите на него, и он скопируется. Кнопка в углу
переключает тёмную и светлую тему (при первом входе тема тёмная).

Ниже по порядку: микрофон, подпись к счётчику, звук оповещения, оформление
счётчика и модель распознавания.

### Микрофон

Список микрофонов Windows; «По умолчанию» — системный микрофон. Под списком
видно, какой микрофон сейчас слушается, или почему он не открылся. Микрофон
переключается без перезагрузки модели, за доли секунды. Если микрофон подключили
уже после запуска, нажмите ⟳. Выбор сохраняется в `settings.json`.

Если выбранный микрофон отключён, модель остаётся в памяти, а на странице
появляется ошибка: достаточно выбрать другой микрофон.

Полоса под списком показывает громкость микрофона. Кнопка «🎧 Слушать себя»
выводит звук микрофона в системные наушники или динамики, чтобы убедиться, что
выбран нужный микрофон (без наушников будет эхо); «⏹ Остановить прослушивание»
выключает его. Прослушивание выключается и само — при смене микрофона и при
перезапуске приложения.

### Подпись к счётчику

Текст рядом с числом, например «Маты за стрим:» (до 40 символов), и где он стоит:
слева, справа, сверху или снизу. Подпись — часть оверлея: в OBS не нужен
отдельный текстовый источник, она двигается и масштабируется вместе с числом
и оформляется в стиле выбранного пресета. Пустое поле — только число. Оверлей
обновляется, как только перестаёте печатать; как это выглядит, видно в превью
оформления.

### Звук оповещения

- **Громкость** — ползунок; оверлей в OBS меняет громкость сразу, без перезагрузки.
  Когда отпускаете ползунок, звук проигрывается на странице, чтобы было слышно результат.
- **«▶ Проверить»** — проиграть выбранный звук на странице управления.
- **Список звуков** — «Стандартный звон» и загруженные звуки (список прокручивается).
  Клик по строке выбирает звук для оверлея, ▶ — прослушать, 🗑 — удалить
  (подтверждается вторым нажатием).
- **«Загрузить звук…»** — MP3, WAV или OGG до 5 МБ, до 30 звуков. Файлы хранятся
  в папке `sounds/`, загруженный звук сразу становится выбранным.

### Оформление счётчика

Выпадающий список пресетов; рядом — живое превью и описание выбранного.
Выбор сразу применяется в оверлее.

### Модель распознавания

Модель выбирается кликом по её карточке. В скобках после названия — движок и
версия модели (например, «Маленькая (Vosk small-ru 0.22)»). Стрелка справа
раскрывает описание и характеристики. Под заголовком раздела видно состояние:
«✓ Модель работает», ход загрузки или ошибка.

Если модель ещё не скачана, по клику она сначала скачивается: в карточке видно,
сколько скачано, а кнопка «Отменить» прерывает скачивание. Недокачанный архив
не считается моделью, поэтому прерванное скачивание ничего не ломает. Когда модель
скачается и распакуется, она включится сама (если за это время не выбрали другую).

Скачанная модель загружается в оперативную память. Это занимает от секунды до пары минут; пока идёт
загрузка, маты не считаются. Полоса показывает оценку по времени: Vosk не сообщает
о ходе загрузки, поэтому приложение запоминает, сколько длилась прошлая загрузка
каждой модели.

Во время загрузки можно выбрать другую модель: загрузка прервётся сразу, и память
освободится. Для этого модель работает в отдельном процессе (`app/stt/vosk_worker.py`),
который при смене модели просто завершается.

Если открыть оверлей в обычном браузере, звук заиграет только после первого
клика по странице: так браузеры защищаются от автозапуска звука. В OBS это не требуется.

## Список слов

Корни для поиска лежат в `words.txt`, по одному на строку. Слово засчитывается,
если начинается с одного из корней. Регистр и ё/е не важны, пустые строки и
строки с `#` пропускаются. После правки файла перезапустите приложение.

## Тесты

Зависимости для тестов (pytest и httpx2 для TestClient) ставятся отдельно:

```powershell
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.venv\Scripts\python.exe -m pytest -q
```

Тесты лежат в `tests/` и выполняются за пару секунд. Им не нужны ни микрофон,
ни модели Vosk, ни интернет: `sounddevice` и `vosk` подменены, файлы
(`counter.json`, `settings.json`, `models/`) создаются во временной папке,
а процесс распознавания проверяется в потоке текущего процесса.
Работающее приложение тесты не трогают, его порты 8765–8774 не занимают.

На GitHub тесты запускаются автоматически для каждого пул-реквеста и коммита
в `main` (`.github/workflows/tests.yml`, Windows).

## Структура

```
app/main.py        точка входа
app/server.py      FastAPI: /ws, /api/state, /api/increment, /api/reset, /api/speech,
                   /api/devices, /api/sound, /api/overlay, статика
app/settings.py    настройки со страницы управления (settings.json)
app/sound.py       громкость и библиотека звуков оповещения (папка sounds/)
app/counter.py     счётчик и сохранение в counter.json
app/profanity.py   поиск корней из words.txt
app/paths.py       пути к файлам (работают и из исходников, и из exe)
app/stt/           распознавание речи: VoskRecognizer, процесс vosk_worker, каталог моделей,
                   скачивание моделей (downloader), список микрофонов (audio_devices)
tests/             тесты pytest (см. «Тесты»)
models/            модели Vosk (в git не попадают)
overlay/           оверлей для OBS; presets.js — оформления, sound.js — проигрыватель звука
control/           страница управления (index.html, style.css, control.js)
```
