# Счётчик матов для OBS

Локальное приложение: слушает речь стримера, находит маты и показывает их
количество в оверлее OBS с анимацией «+1» и звуком.

Схема: микрофон → распознавание речи → поиск матов → счётчик → WebSocket → HTML-оверлей.

Речь распознаётся офлайн через [Vosk](https://alphacephei.com/vosk/):
интернет не нужен, звук никуда не отправляется.

## Установка

Нужен Python и виртуальное окружение `.venv` в корне проекта.

```powershell
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### Модель распознавания

Приложение работает с моделями из каталога `app/stt/catalog.py`. Скачайте
архив нужной модели и распакуйте его в папку `models/`:

| Модель    | Архив                                                                   | На диске | Память  | Загрузка  |
|-----------|-------------------------------------------------------------------------|----------|---------|-----------|
| Маленькая | [vosk-model-small-ru-0.22](https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip) | 90 МБ    | ~0,3 ГБ | ~1 с      |
| Большая   | [vosk-model-ru-0.42](https://alphacephei.com/vosk/models/vosk-model-ru-0.42.zip)             | 3,5 ГБ   | ~5,5 ГБ | 1,5–2 мин |

```
models/vosk-model-small-ru-0.22/am, conf, graph, ...
```

Маленькая быстрая, но распознаёт хуже; большая заметно точнее, но требует много
памяти. По умолчанию запускается первая скачанная модель из каталога.
Выбор на странице управления сохраняется в `settings.json`.

Чтобы добавить модель, допишите её в `CATALOG` в `app/stt/catalog.py`:
название, описание, характеристики и ссылку на архив.

## Запуск

```powershell
.venv\Scripts\python.exe -m app.main
```

Ключи запуска:

| Ключ             | Что делает                                                 |
|------------------|------------------------------------------------------------|
| `--list-devices` | показать звуковые устройства и выйти                       |
| `--device N`     | слушать устройство с номером `N` или по части названия     |

По умолчанию слушается системный микрофон Windows. Если в логе
`Слушаю микрофон: ...` указан не тот, выберите нужный через `--device`:

```powershell
.venv\Scripts\python.exe -m app.main --list-devices
.venv\Scripts\python.exe -m app.main --device 1
```

Сервер работает только на этом компьютере (`127.0.0.1:8765`). Остановить: `Ctrl+C`.

Если порт 8765 занят другой программой, приложение само попробует 8766, 8767
и так далее (до 8774) и напишет в консоли, какой адрес получился. В этом случае
адрес оверлея в OBS нужно поменять на новый или освободить порт 8765.

- Оверлей для OBS: http://localhost:8765/overlay/
- Страница управления: http://localhost:8765/control/

Значение счётчика хранится в `counter.json` и не теряется после перезапуска.

## Добавление в OBS

1. В нужной сцене в «Источниках» нажмите **+** → **Браузер**.
2. **URL:** `http://localhost:8765/overlay/`
3. **Ширина / высота:** например `400` × `300`. Для крупного шрифта увеличьте оба размера, чтобы надпись «+1» не обрезалась сверху.
4. Включите **«Управлять звуком через OBS»**: тогда звук «дилинь» появится в микшере OBS и попадёт в эфир.
5. Пользовательский CSS можно не трогать: фон оверлея и так прозрачный.

Параметры оверлея задаются в адресе:

| Параметр   | Что делает                       | По умолчанию |
|------------|----------------------------------|--------------|
| `size`     | размер числа в пикселях          | `120`        |
| `color`    | цвет числа (hex без `#`)         | `ffffff`     |
| `mute=1`   | отключить звук                   | звук включён |

Пример: `http://localhost:8765/overlay/?size=160&color=ffcc00`

Если приложение запущено после OBS или было перезапущено, оверлей
переподключится сам в течение пары секунд.

### Свой звук

Положите файл `overlay/sounds/ding.mp3`, и он будет играть вместо встроенного
синтезированного звона.

## Страница управления

Откройте http://localhost:8765/control/ в обычном браузере (в OBS её добавлять
не нужно). Там видно текущее значение и состояние подключения, есть кнопки
«+1 (тест)» и «Сбросить» (сброс подтверждается вторым нажатием). Внизу —
адрес оверлея для OBS: нажмите на него, и он скопируется.

Ниже выбирается модель распознавания: в списке или кликом по карточке с её
описанием. Карточки видны сразу; кнопка «i» сворачивает их.

Выбранная модель загружается в оперативную память (скачивать её при этом не нужно:
она уже лежит в `models/`). Это занимает от секунды до пары минут; пока идёт
загрузка, маты не считаются. Полоса показывает оценку по времени: Vosk не сообщает
о ходе загрузки, поэтому приложение запоминает, сколько длилась прошлая загрузка
каждой модели.

Во время загрузки можно выбрать другую модель: загрузка прервётся сразу, и память
освободится. Для этого модель работает в отдельном процессе (`app/stt/vosk_worker.py`),
который при смене модели просто завершается.

Если открыть оверлей в обычном браузере, звук заиграет только после первого
клика по странице: так браузеры защищаются от автозапуска звука. В OBS это не требуется.

## Список слов

Корни для поиска лежат в `words.txt`, по одному на строку. Слово засчитывается,
если начинается с одного из корней. Регистр и ё/е не важны, пустые строки и
строки с `#` пропускаются. После правки файла перезапустите приложение.

## Структура

```
app/main.py        точка входа
app/server.py      FastAPI: /ws, /api/state, /api/increment, /api/reset, /api/speech, статика
app/settings.py    настройки со страницы управления (settings.json)
app/counter.py     счётчик и сохранение в counter.json
app/profanity.py   поиск корней из words.txt
app/paths.py       пути к файлам (работают и из исходников, и из exe)
app/stt/           распознавание речи: VoskRecognizer, процесс vosk_worker, каталог моделей
models/            модели Vosk (в git не попадают)
overlay/           оверлей для OBS
control/           страница управления
```
