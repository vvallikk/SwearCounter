# Безопасность

## Поддерживаемые версии

Исправления выходят только для последней версии. Программа сама предлагает обновиться,
проверить вручную можно в разделе "Обновления".

## Как сообщить об уязвимости

Не создавайте открытый issue. Напишите закрыто через
[Report a vulnerability](https://github.com/vvallikk/SwearCounter/security/advisories/new)
на странице репозитория. Опишите, что именно не так, как это воспроизвести и на какой версии.

Я отвечу в течение недели. Если уязвимость подтвердится, выпущу исправление
и упомяну вас в заметках к релизу, если вы не против.

## Что уже сделано

- Сервер слушает только 127.0.0.1 и принимает запросы с адресом localhost: чужие сайты
  не могут управлять счётчиком, в том числе через подмену DNS.
- Команды, меняющие состояние, принимаются только со страниц самой программы.
- Обновление скачивается только с GitHub и проверяется по контрольной сумме SHA-256.
- Личные оформления проверяются при установке: допустимые типы файлов, размер,
  пути внутри архива. Анимация в них работает как небольшая программа внутри оверлея,
  поэтому ставьте их только из надёжных источников.
- Речь распознаётся на компьютере, звук никуда не отправляется.
