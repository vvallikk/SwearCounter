# Название: Слова-паразиты
#
# Список корней: по одному на строку. Слово засчитывается, если начинается
# с одного из корней (регистр и ё/е не важны): «буквально» засчитает и «буквальный».
# Пустые строки и строки с # игнорируются. Фразы из нескольких слов
# («как бы», «в общем») не поддерживаются: ищется каждое слово отдельно.
#
# Корень не должен быть началом обычного слова: например, «ну» засчитала бы
# «нужно», а «чё» — «чёрный». Поэтому здесь «короче», а не «короч» (иначе
# засчитается «корочка»). «блин» засчитает и «блины» — уберите, если мешает.
#
# Файл можно править, не закрывая программу: изменения подхватываются сами.
