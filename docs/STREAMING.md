# Twitch и YouTube

Раздел «Трансляции» на вкладке настроек подключает счётчик к чату стрима. Интеграции
выключены по умолчанию: пока они не включены, программа не обращается ни к Twitch, ни к YouTube.

## Что умеет

| Возможность | Twitch | YouTube |
| --- | --- | --- |
| Команда `!маты` показывает счёт | ответ в чат | только учитывается (ответить нельзя) |
| Модератор: `!маты +3`, `!маты сброс` | да | да |
| Объявление в чат на особых числах и цели, каждые N слов | да | нет |
| Слова за биты («штраф от зрителей») | да | — |
| Слова за Super Chat / Super Sticker | — | да |
| Маркер на таймлайне трансляции при слове | да | нет |

Команду и текст ответа можно поменять. В ответе и объявлении работают подстановки
`{count}` (текущий счёт), `{milestone}` (достигнутое число), `{user}` (кто спросил).
Модераторами считаются владелец канала, модераторы и (на Twitch) бейдж broadcaster.
Одно сообщение прибавляет не больше 100 слов.

## Twitch

1. Получите токен доступа пользователя (например, в генераторе токенов Twitch) с правами
   `chat:read` и `chat:edit`. Для маркеров нужно ещё `channel:manage:broadcast`, а токен
   должен принадлежать владельцу того же канала.
2. В разделе «Трансляции» впишите канал (имя или ссылка) и токен, включите «Чат Twitch»,
   нажмите «Сохранить». Статус «Чат Twitch на связи» значит, что всё в порядке.
3. «Проверить чат Twitch» отправляет в чат текущий ответ на команду.

Ответы не чаще, чем раз в заданную паузу (для зрителей); модераторам отвечаем всегда.
Исходящие сообщения идут с паузой 1,5 с, чтобы не упереться в лимит Twitch.

## YouTube

1. В Google Cloud Console включите YouTube Data API v3 и создайте ключ API.
2. Впишите ключ и ссылку на идущую трансляцию (или её код), включите «Чат YouTube».
3. Квота: один запрос чата стоит 5 единиц из суточных 10 000, программа опрашивает чат не чаще
   раза в 10 секунд — этого хватает примерно на 5–6 часов трансляции в сутки. При исчерпании
   квоты статус покажет ошибку, подключение повторится позже.

С одним ключом API чат можно только читать: ответить от имени канала YouTube разрешает
лишь после входа в аккаунт Google (OAuth), этого в программе нет. Счёт зрители видят в оверлее.
Сообщения, которые были в чате до подключения, не учитываются.

## Приватность

- Токен и ключ API хранятся в `settings.json` на этом компьютере и не отдаются обратно
  в браузер (страница видит только факт, что значение сохранено).
- Токен уходит только в Twitch, ключ — только в YouTube.
- Текст сообщений чата не сохраняется и не записывается в журнал.
