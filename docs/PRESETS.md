# Личные оформления

Личное оформление — это zip-архив, который автор делает на заказ для конкретного человека:
свой шрифт, картинки, анимация прибавления и звук. Архив не входит в программу и её
репозиторий, поэтому оформление есть только у того, кому его прислали.

Набор можно сделать и самому по этой инструкции, а можно заказать у автора: в разделе
«Оформление» есть ссылка «заказать у автора», она готовит письмо с описанием заказа.

Архив ставится кнопкой «Установить оформление…» в разделе «Оформление» окна программы
или по ссылке на облако (см. «Как передать набор»). Набор распаковывается в папку
`presets\<id>` рядом с `SwearCounter.exe`, переживает обновления и появляется в списке
в группе «Личные оформления». Там же кнопка «🗑 Удалить оформление». Повторная установка
архива с тем же `id` заменяет прежнюю версию.

## Как сделать набор

Нужны только Проводник, Блокнот (или любой редактор текста) и сама программа.

1. **Создайте папку** с названием набора, например `vasya-gold`, и положите в неё
   `preset.json` (обязательно) и, по желанию, `style.css`, `animation.js`, картинки, шрифты
   и звук. Что писать в каждом файле, описано ниже, в разделе «Состав архива».
   Сохраняйте файлы в кодировке UTF-8 (в Блокноте она выбрана по умолчанию).
2. **Сожмите папку в zip:** правой кнопкой по папке, «Отправить» → «Сжатая ZIP-папка»
   (в Windows 11: «Сжать в ZIP-файл»).
3. **Установите архив** кнопкой «Установить оформление…» в разделе «Оформление».
4. **Проверьте набор**, как описано в разделе «Проверка набора». Чтобы исправить что-то,
   поправьте файлы, снова сожмите папку и установите архив: новая версия заменит старую.

## Проверка набора

Программа проверяет архив при установке. Если с ним что-то не так, оформление
не установится, а под кнопками появится понятная ошибка, например:

- «В архиве нет preset.json» или «preset.json не читается: проверьте, что это JSON в UTF-8»
  (часто это лишняя или пропущенная запятая, кавычка или скобка);
- «В preset.json нет title», «color в preset.json: цвет вида #ffcc00» и другие ошибки полей;
- «Звука coin.mp3 нет в архиве» (имя в `sound` должно совпадать с файлом, включая папку);
- «Файл … не подходит для оформления» (тип файла не из списка разрешённых),
  «Архив больше 20 МБ», «В архиве больше 200 файлов».

Что программа проверить не может, смотрите глазами:

1. Выберите оформление в списке и посмотрите на превью под ним.
2. Нажмите «+1 (тест)» вверху окна: так видно анимацию прибавления и слышно звук.
3. Нажмите «Открыть в браузере» рядом со ссылкой на оверлей, чтобы увидеть его в полный размер.
4. Если не подхватилась картинка или шрифт, проверьте путь в `style.css`: он считается
   от `style.css`, и регистр букв в имени файла важен для OBS.
5. Если вместо своей анимации играет встроенная, в `animation.js` ошибка. Откройте оверлей
   в браузере, нажмите F12, вкладка «Console»: там будет текст ошибки. Затем нажмите
   «+1 (тест)» в программе и посмотрите, что появится в консоли.

Чтобы не пересобирать архив после каждой правки, можно менять файлы прямо в установленной
папке `presets\<id>` рядом с `SwearCounter.exe` и обновлять оверлей в браузере клавишей F5.
Когда всё готово, получите архив кнопкой «📦 Сохранить архивом»: он сохранится в «Загрузки».
Не меняйте `id` в установленной папке: он должен совпадать с названием папки, иначе
набор пропадёт из списка.

## Как передать набор

1. **Соберите архив**, как в разделе «Как сделать набор», или нажмите
   «📦 Сохранить архивом» у установленного набора: архив сохранится в «Загрузки» и
   откроется в Проводнике.
2. **Загрузите архив в облако** и откройте доступ по ссылке. Подходят бесплатные:
   - Яндекс Диск: «Поделиться», ссылка вида `https://disk.yandex.ru/d/...`;
   - Google Диск: «Поделиться», доступ «Все, у кого есть ссылка»;
   - Dropbox: «Копировать ссылку»;
   - или любая прямая ссылка на zip (например, вложение в релизе GitHub).
3. **Отправьте ссылку.** Покупатель нажимает «Установить по ссылке…» в разделе
   «Оформление» и вставляет её. Программа сама скачивает архив (до 20 МБ), проверяет и
   включает оформление. Если доступ по ссылке не открыт, она так и скажет.

Ссылку можно отправить и в общий чат: оформление поставит любой, у кого она есть.
Для личного набора отправляйте её лично или закройте доступ после установки.

## Защита и лицензия

Программа под GPL-3.0, поэтому проверку «кто имеет право на набор» в коде любой может
убрать. Её и нет: набор защищает то, **как он распространяется**, а не DRM.

- Архив передаётся только покупателю (личным сообщением, ссылкой с ограниченным доступом).
- Картинки, звуки, шрифты и стили набора — не часть программы. Это отдельная работа
  автора, на неё действует собственная лицензия, а не GPL. Положите в архив `LICENSE.txt`,
  например: «Только для личного использования <имя>, передача и перепродажа запрещены».
- Поле `owner` показывается в окне программы («Личное оформление для: …»). Это не защита,
  а подпись: по ней видно, чей набор, если он всплывёт у кого-то ещё.
- `animation.js` тоже работа автора. Если хотите, чтобы его можно было свободно
  дорабатывать, укажите это в лицензии набора отдельно.

## Состав архива

Файлы лежат в корне архива или в одной общей папке (так получается при «Сжать папку»
в Проводнике):

```
preset.json      описание набора (обязательно)
style.css        оформление (необязательно)
animation.js     своя анимация прибавления (необязательно)
LICENSE.txt      лицензия набора (рекомендуется)
coin.mp3         звук, картинки, шрифты — что угодно из списка ниже
img/coin.png
```

Ограничения: архив и распакованные файлы — до 20 МБ, не больше 200 файлов, до 50 наборов.
Разрешены только `.json .css .js .txt .md .png .jpg .jpeg .gif .webp .svg .woff .woff2 .ttf
.otf .mp3 .wav .ogg`. Пути с `..`, абсолютные пути и имена дисков отклоняются; служебные
файлы архиваторов (`__MACOSX`, `.DS_Store`, `Thumbs.db`, `desktop.ini`) пропускаются.

### preset.json

```json
{
  "id": "vasya-gold",
  "title": "Золото Васи",
  "description": "Золотые цифры, монетки и звон кассы.",
  "owner": "Вася",
  "color": "#ffd700",
  "animation": "explosion",
  "sound": "coin.mp3"
}
```

| Поле          | Что это                                                                 |
|---------------|-------------------------------------------------------------------------|
| `id`          | обязательно; 1–32 символа: `a-z`, `0-9`, `-`. Не может совпадать со встроенными (`classic`, `neon`…) |
| `title`       | обязательно; название в списке, до 40 символов                          |
| `description` | описание под списком, до 300 символов                                   |
| `owner`       | для кого набор, до 40 символов                                           |
| `color`       | цвет цифр по умолчанию: `#rgb`, `#rrggbb` или `#rrggbbaa`; без него белый |
| `animation`   | id встроенной анимации, если своей в `animation.js` нет; без него — «Классика» |
| `sound`       | путь к звуку в архиве (`.mp3`, `.wav`, `.ogg`) — стандартный звук оформления |

Файлы набора доступны оверлею по адресу `/overlay/custom/<id>/<путь>`.

### style.css

Оверлей ставит `data-preset="<id>"` на `<html>`, поэтому все правила пишутся под
`:root[data-preset="<id>"]`, чтобы не задеть другие оформления. Разметка оверлея:

```html
<div id="counter" class="counter">
  <span id="label" class="label">подпись</span>
  <div id="number" class="number">
    <span id="glow" class="glow"></span>   <!-- вспышка -->
    <span id="value" class="value">0</span> <!-- число -->
    <!-- сюда добавляется .plus — уплывающее «+1» -->
  </div>
</div>
```

Переменные: `--size` (размер цифр, подстраивается под окно), `--color` (цвет цифр:
`color` из preset.json или `?color=` в адресе), `--label-size`. Пути в `url()` считаются от
самого `style.css`, так что картинки и шрифты набора подключаются относительными путями:

```css
@font-face {
  font-family: "VasyaGold";
  src: url("fonts/gold.woff2") format("woff2");
}

:root[data-preset="vasya-gold"] body {
  font-family: "VasyaGold", "Segoe UI", sans-serif;
}

:root[data-preset="vasya-gold"] .value {
  -webkit-text-stroke: calc(var(--size) * 0.05) #5a3b00;
  text-shadow: 0 0 calc(var(--size) * 0.15) #ffb300;
}

:root[data-preset="vasya-gold"] .glow {
  background: url("img/coin.png") center / contain no-repeat;
}
```

Если берёте встроенную анимацию полем `animation`, задайте и переменные, которыми
пользуются её стили: для `explosion` — `--accent`.

### animation.js

Скрипт подключается на странице оверлея и регистрирует анимацию прибавления:

```js
registerOverlayAnimation("vasya-gold", (delta, api) => {
  // Монетка падает сверху на число
  const coin = document.createElement("img");
  coin.src = api.base + "img/coin.png";
  coin.style.cssText = `position:absolute;left:50%;top:0;width:${api.size * 0.6}px;pointer-events:none`;
  api.number.appendChild(coin);
  coin.animate(
    [
      { transform: "translate(-50%, -200%)", opacity: 0 },
      { transform: "translate(-50%, 0)", opacity: 1, offset: 0.6 },
      { transform: "translate(-50%, 0)", opacity: 0 },
    ],
    { duration: 900, easing: "ease-in" }
  ).onfinish = () => coin.remove();

  api.value.animate([{ transform: "scale(1)" }, { transform: "scale(1.25)" }, { transform: "scale(1)" }], 400);
  api.floatPlus(delta);
});
```

`delta` — на сколько вырос счёт. Что есть в `api`:

| Поле        | Что это                                                           |
|-------------|-------------------------------------------------------------------|
| `root`      | `<html>`                                                          |
| `counter`, `number`, `value`, `label`, `glow` | элементы разметки выше          |
| `size`      | текущий размер цифр в пикселях                                    |
| `base`      | адрес файлов набора, `/overlay/custom/<id>/`                       |
| `floatPlus(delta, keyframes?, options?)` | уплывающее «+N»; кадры и параметры Web Animations можно заменить |
| `builtin`   | встроенные анимации по id: `api.builtin.explosion(delta)`          |

Если анимация бросит исключение, оверлей запишет ошибку в консоль и сыграет встроенную.
Скрипт выполняется в оверлее (в OBS — в браузерном источнике), поэтому пользователю стоит
ставить только оформления из надёжных источников. Об этом написано рядом с кнопкой установки.

## Для разработчиков

Если программа запущена из исходников (см. [DEVELOPMENT.md](DEVELOPMENT.md)), папку набора
можно положить в `presets/<id>/` в корне репозитория (она в `.gitignore`). Набор, положенный
вручную с ошибкой в `preset.json`, просто не появится в списке, а причина будет в журнале
(`swearcounter.log` или консоль при `--console`). Архив собирается и проверяется теми же
правилами, что и при установке, скриптом
`.venv\Scripts\python.exe scripts/pack_preset.py private/vasya-gold`: он кладёт `<id>.zip`
рядом с папкой (другое место: `-o путь.zip`).
