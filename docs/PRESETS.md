# Личные оформления

Личное оформление — это zip-архив, который автор делает на заказ для конкретного человека:
свой шрифт, картинки, анимация прибавления и звук. Архив не входит в программу и её
репозиторий, поэтому оформление есть только у того, кому его прислали.

Пользователь ставит архив кнопкой «Установить оформление…» в разделе «Оформление»
окна программы. Набор распаковывается в папку `presets/<id>/` рядом с `SwearCounter.exe`,
переживает обновления и появляется в списке в группе «Личные оформления». Там же кнопка
«🗑 Удалить оформление». Повторная установка архива с тем же `id` заменяет прежнюю версию.

## Защита и лицензия

Программа под GPL-3.0, поэтому проверку «кто имеет право на набор» в коде любой может
убрать. Её и нет: набор защищает то, **как он распространяется**, а не DRM.

- Архив передаётся только покупателю (личным сообщением, ссылкой с ограниченным доступом).
- Картинки, звуки, шрифты и стили набора — не часть программы. Это отдельная работа
  автора, на неё действует собственная лицензия, а не GPL. Положите в архив `LICENSE.txt`,
  например: «Только для личного использования <имя>, передача и перепродажа запрещены».
- Поле `owner` показывается в окне программы («Личное оформление для: …»). Это не защита,
  а подпись: по ней видно, чей набор, если он всплывёт у кого-то ещё.
- `animation.js` тоже работа автора. Если хотите, чтобы его можно было свободно
  дорабатывать, укажите это в лицензии набора отдельно.

## Состав архива

Файлы лежат в корне архива или в одной общей папке (так получается при «Сжать папку»
в Проводнике):

```
preset.json      описание набора (обязательно)
style.css        оформление (необязательно)
animation.js     своя анимация прибавления (необязательно)
LICENSE.txt      лицензия набора (рекомендуется)
coin.mp3         звук, картинки, шрифты — что угодно из списка ниже
img/coin.png
```

Ограничения: архив и распакованные файлы — до 20 МБ, не больше 200 файлов, до 50 наборов.
Разрешены только `.json .css .js .txt .md .png .jpg .jpeg .gif .webp .svg .woff .woff2 .ttf
.otf .mp3 .wav .ogg`. Пути с `..`, абсолютные пути и имена дисков отклоняются; служебные
файлы архиваторов (`__MACOSX`, `.DS_Store`, `Thumbs.db`, `desktop.ini`) пропускаются.

### preset.json

```json
{
  "id": "vasya-gold",
  "title": "Золото Васи",
  "description": "Золотые цифры, монетки и звон кассы.",
  "owner": "Вася",
  "color": "#ffd700",
  "animation": "explosion",
  "sound": "coin.mp3"
}
```

| Поле          | Что это                                                                 |
|---------------|-------------------------------------------------------------------------|
| `id`          | обязательно; 1–32 символа: `a-z`, `0-9`, `-`. Не может совпадать со встроенными (`classic`, `neon`…) |
| `title`       | обязательно; название в списке, до 40 символов                          |
| `description` | описание под списком, до 300 символов                                   |
| `owner`       | для кого набор, до 40 символов                                           |
| `color`       | цвет цифр по умолчанию: `#rgb`, `#rrggbb` или `#rrggbbaa`; без него белый |
| `animation`   | id встроенной анимации, если своей в `animation.js` нет; без него — «Классика» |
| `sound`       | путь к звуку в архиве (`.mp3`, `.wav`, `.ogg`) — стандартный звук оформления |

Файлы набора доступны оверлею по адресу `/overlay/custom/<id>/<путь>`.

### style.css

Оверлей ставит `data-preset="<id>"` на `<html>`, поэтому все правила пишутся под
`:root[data-preset="<id>"]`, чтобы не задеть другие оформления. Разметка оверлея:

```html
<div id="counter" class="counter">
  <span id="label" class="label">подпись</span>
  <div id="number" class="number">
    <span id="glow" class="glow"></span>   <!-- вспышка -->
    <span id="value" class="value">0</span> <!-- число -->
    <!-- сюда добавляется .plus — уплывающее «+1» -->
  </div>
</div>
```

Переменные: `--size` (размер цифр, подстраивается под окно), `--color` (цвет цифр:
`color` из preset.json или `?color=` в адресе), `--label-size`. Пути в `url()` считаются от
самого `style.css`, так что картинки и шрифты набора подключаются относительными путями:

```css
@font-face {
  font-family: "VasyaGold";
  src: url("fonts/gold.woff2") format("woff2");
}

:root[data-preset="vasya-gold"] body {
  font-family: "VasyaGold", "Segoe UI", sans-serif;
}

:root[data-preset="vasya-gold"] .value {
  -webkit-text-stroke: calc(var(--size) * 0.05) #5a3b00;
  text-shadow: 0 0 calc(var(--size) * 0.15) #ffb300;
}

:root[data-preset="vasya-gold"] .glow {
  background: url("img/coin.png") center / contain no-repeat;
}
```

Если берёте встроенную анимацию полем `animation`, задайте и переменные, которыми
пользуются её стили: для `explosion` — `--accent`.

### animation.js

Скрипт подключается на странице оверлея и регистрирует анимацию прибавления:

```js
registerOverlayAnimation("vasya-gold", (delta, api) => {
  // Монетка падает сверху на число
  const coin = document.createElement("img");
  coin.src = api.base + "img/coin.png";
  coin.style.cssText = `position:absolute;left:50%;top:0;width:${api.size * 0.6}px;pointer-events:none`;
  api.number.appendChild(coin);
  coin.animate(
    [
      { transform: "translate(-50%, -200%)", opacity: 0 },
      { transform: "translate(-50%, 0)", opacity: 1, offset: 0.6 },
      { transform: "translate(-50%, 0)", opacity: 0 },
    ],
    { duration: 900, easing: "ease-in" }
  ).onfinish = () => coin.remove();

  api.value.animate([{ transform: "scale(1)" }, { transform: "scale(1.25)" }, { transform: "scale(1)" }], 400);
  api.floatPlus(delta);
});
```

`delta` — на сколько вырос счёт. Что есть в `api`:

| Поле        | Что это                                                           |
|-------------|-------------------------------------------------------------------|
| `root`      | `<html>`                                                          |
| `counter`, `number`, `value`, `label`, `glow` | элементы разметки выше          |
| `size`      | текущий размер цифр в пикселях                                    |
| `base`      | адрес файлов набора, `/overlay/custom/<id>/`                       |
| `floatPlus(delta, keyframes?, options?)` | уплывающее «+N»; кадры и параметры Web Animations можно заменить |
| `builtin`   | встроенные анимации по id: `api.builtin.explosion(delta)`          |

Если анимация бросит исключение, оверлей запишет ошибку в консоль и сыграет встроенную.
Скрипт выполняется в оверлее (в OBS — в браузерном источнике), поэтому пользователю стоит
ставить только архивы от автора программы. Об этом написано рядом с кнопкой установки.

## Проверка набора

1. Запустите программу из исходников (`.venv\Scripts\python.exe -m app.main --console`, см. [DEVELOPMENT.md](DEVELOPMENT.md)).
2. Положите папку набора в `presets/<id>/` в корне репозитория (папка в `.gitignore`)
   или установите zip кнопкой в окне.
3. Выберите оформление в списке. После правок файлов обновите превью или оверлей (F5):
   набор подключается при загрузке страницы.
4. Ошибки `preset.json` видны при установке, а для папки, положенной вручную, — в журнале
   (`swearcounter.log` или консоль): такой набор просто не появится в списке.
