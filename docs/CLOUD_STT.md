# Облачное распознавание речи

Кроме локальных моделей (Vosk, GigaAM, Whisper…) SwearCounter умеет отправлять
фразы на облачные сервисы распознавания по их API. Это **необязательная** функция:
пока вы не введёте API-ключ и не выберете облачную модель, звук не покидает компьютер.

## Сервисы и модели

| Сервис | Модели | Ключ берут здесь |
|---|---|---|
| Deepgram | Nova-2, Nova-3 | https://console.deepgram.com/ |
| OpenAI | gpt-4o-mini-transcribe, gpt-4o-transcribe, whisper-1 | https://platform.openai.com/api-keys |
| Groq | whisper-large-v3-turbo, whisper-large-v3 | https://console.groq.com/keys |
| ElevenLabs | Scribe v2 | https://elevenlabs.io/app/settings/api-keys |

Для каждого языка (русский, английский) в списке моделей на странице управления есть
свой набор карточек с пометкой «облако».

## Как включить

1. На странице управления откройте список моделей и найдите карточку «Облако: <сервис>».
2. Вставьте API-ключ в поле карточки и нажмите «Сохранить ключ».
3. Нажмите «Скачать» — скачается только детектор речи (около 2 МБ), он выделяет фразы локально.
4. Выберите модель кликом по карточке.

Ключ можно удалить кнопкой «Удалить ключ» в той же карточке. Если по этому ключу работает
выбранная модель, распознавание перезапускается и ждёт новый ключ.

## Как это работает

- Локальный детектор речи (Silero VAD) режет звук на законченные фразы — как у GigaAM и Whisper.
- Каждая фраза уходит одним HTTPS-запросом (WAV 16 кГц, моно). Тишина и фразы короче
  0,25 с в облако не отправляются, за них платить не придётся.
- Промежуточных результатов нет: счётчик увеличивается, когда сервис вернул текст фразы.
- Ответ 401/402/403 (неверный ключ, закончились деньги) останавливает распознавание
  с понятным сообщением; сеть, перегрузка и лимиты запросов пропускают только одну фразу.
- Таймаут одного запроса — 20 секунд.

## Приватность и безопасность

- В облако уходит только звук законченных фраз и только к выбранному вами сервису.
- Ключ хранится в `settings.json` рядом с программой **открытым текстом**. Не публикуйте этот
  файл и не показывайте его на стриме.
- Ключ не возвращается через API программы и не попадает в адрес запроса и журнал.
  Страница управления видит только признак «ключ есть».
- Сайты из интернета не могут задать или удалить ключ: запросы с чужим `Origin` отклоняются.

## Стоимость

Тарифы у сервисов разные и меняются; смотрите актуальные цены на их сайтах. Например,
Groq считает минимум 10 секунд на запрос, поэтому для коротких фраз он может оказаться
дороже, чем кажется.

## Разработка

Код — `app/stt/cloud.py`; каталог облачных моделей генерируется в `app/stt/catalog.py`
(`_CLOUD_MODELS`). Чтобы добавить сервис, опишите `Provider` в `PROVIDERS`, формат запроса в
`build_request`, разбор ответа в `parse_response` и модели в `_CLOUD_MODELS`. Тесты:
`tests/test_cloud.py` (запросы и ответы проверяются без сети, `urlopen` подменяется).
