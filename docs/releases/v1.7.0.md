## Что нового

- Окно "Что нового" с двумя вкладками: заметки о версии и вся история изменений. Оно открывается при запуске, когда вышла новая версия или программа только что обновилась, а вызвать его можно в любой момент из раздела "Обновления".
- Напоминание об обновлении в трее: уведомление при запуске, пункт меню "Обновиться до vX.Y.Z" и пометка в подсказке значка.
- Автообновление: при запуске программа сама скачивает новую версию и перезапускается. По умолчанию выключено, программа предложит включить его в окне "Что нового"; переключатель есть и в разделе "Обновления".

## What's new

- A "What's new" window with two tabs: notes for the version and the full changelog. It opens at startup when a new version is out or the program has just been updated, and you can open it any time from the "Updates" section.
- An update reminder in the tray: a notification at startup, an "Update to vX.Y.Z" menu item and a note in the icon tooltip.
- Automatic updates: at startup the program downloads the new version by itself and restarts. It is off by default; the program offers to turn it on in the "What's new" window, and there is a switch in the "Updates" section too.
