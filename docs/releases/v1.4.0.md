## Что нового

- В описании каждого релиза теперь есть раздел "Проверка файла": SHA-256 архива и результат проверки на VirusTotal со ссылкой на полный отчёт. По ним можно убедиться, что скачанный архив тот самый и посмотреть, что о нём думают антивирусы.
- В окне обновления этот раздел не показывается, там остаются только заметки к версии.

## What's new

- Every release description now has a "Проверка файла" (File check) section: the archive's SHA-256 and the VirusTotal result with a link to the full report. Use them to make sure the downloaded archive is the right one and see what antivirus engines think of it.
- The update window does not show this section, only the release notes.
