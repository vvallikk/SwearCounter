## Что нового

- В описании каждого релиза теперь есть раздел "Проверка файла": SHA-256 архива и результат проверки на VirusTotal со ссылкой на полный отчёт. По ним можно убедиться, что скачанный архив тот самый и что антивирусы ничего в нём не нашли.
- Подготовлена подпись программы сертификатом SignPath Foundation: когда она заработает, Windows перестанет предупреждать о неизвестном издателе. Политика подписи и приватности описана в [CODE_SIGNING.md](https://github.com/vvallikk/SwearCounter/blob/main/docs/CODE_SIGNING.md).
- В окне обновления этот раздел не показывается, там остаются только заметки к версии.

## What's new

- Every release description now has a "Проверка файла" (File check) section: the archive's SHA-256 and the VirusTotal result with a link to the full report. Use them to make sure the downloaded archive is the right one and that antivirus engines found nothing in it.
- Code signing with a SignPath Foundation certificate is set up: once it is active, Windows will stop warning about an unknown publisher. The signing and privacy policy is in [CODE_SIGNING.md](https://github.com/vvallikk/SwearCounter/blob/main/docs/CODE_SIGNING.md).
- The update window does not show this section, only the release notes.
