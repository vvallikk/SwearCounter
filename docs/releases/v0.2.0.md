## Что нового

- Программа стала обычным приложением Windows: своё окно и значок в трее вместо консоли. Закрытие окна прячет программу в трей, счёт продолжается.
- Обновления прямо из программы: она сама сообщает о новой версии, скачивает и устанавливает её в один клик. Счёт, настройки, звуки и модели сохраняются.
- Модели распознавания скачиваются из окна программы одним кликом, с прогрессом и отменой.
- Подпись к числу («Маты за стрим:») — слева, справа, сверху или снизу.
- Число автоматически подстраивается под размер источника в OBS.
- Выбор оформления выпадающим списком с живым превью; новое оформление.
- Звук оповещения проверяется сразу, без задержки.
- Защита от запросов с посторонних сайтов к программе.

## What's new

- The program is now a regular Windows app: its own window and a tray icon instead of a console. Closing the window hides it to the tray, and counting continues.
- In-app updates: the program tells you about a new version, then downloads and installs it in one click. The count, settings, sounds and models are kept.
- Speech recognition models download from the program window in one click, with progress and cancel.
- A caption next to the number ("Swears this stream:") placed left, right, above or below.
- The number automatically fits the size of the OBS source.
- Style picker as a dropdown with a live preview, plus a new style.
- The alert sound preview plays instantly.
- Protection against requests to the program from other websites.
