## Что нового

- Пауза распознавания: кнопка в окне программы и пункт в меню трея. Пригодится на перерыв, катсцену или когда в микрофон попадает чужой голос. Пока пауза включена, счёт не растёт.
- Горячие клавиши: "+1", пауза и сброс счёта работают, даже когда окно свёрнуто и вы в игре. По умолчанию "+1" — Ctrl+Shift+F9, пауза — Ctrl+Shift+F10, сброс без клавиши. Сочетания меняются на вкладке "Настройки".

## What's new

- Recognition pause: a button in the program window and an item in the tray menu. Handy for a break, a cutscene or when someone else's voice gets into the microphone. While paused, the count doesn't grow.
- Hotkeys: "+1", pause and reset work even when the window is minimized and you're in a game. By default "+1" is Ctrl+Shift+F9, pause is Ctrl+Shift+F10, reset has no key. Change the combinations on the "Settings" tab.
